# Unofficial Shortcut Client
A high-performance Android client for Shortcut (formerly Clubhouse), built with React Native and Expo.

## ⚠️ Disclaimer
This is an **unofficial** application. It is not affiliated with, maintained by, or endorsed by Shortcut Software. This project is an effort to provide a mobile-first experience for the Shortcut API.

## 🔒 Security & Privacy
- **Zero Backend:** Your API tokens never leave your device.
- **Hardware Encryption:** Tokens are stored using Android Keystore/iOS Keychain via `expo-secure-store`.
- **Open Source:** Every line of code is auditable to ensure your data stays private.

## Tech Stack
- **Framework:** React Native (Expo)
- **Language:** TypeScript
- **State Management:** TanStack Query
- **Styling:** Tailwind CSS (via NativeWind)
